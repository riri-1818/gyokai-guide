40社の有価証券報告書を横に並べると

各ページの「有価証券報告書で比べる」では、業界ごとに主要2〜6社、合計40社の最新の有価証券報告書（2026年提出）を実際に読み込みました。ここでは業界をまたいで並べます。

ROE（自己資本利益率）とは？

株主から預かったお金100円を使って、1年で何円の利益を出したかを表す数字です。ROE10%なら100円で10円稼いだことになります。日本では「8%を超えるのが目安」とよく言われます。

業界をまたいで見えたこと

  • 「業界」より「会社」で差がつく。 自動車ではトヨタ10.1%に対して日産-10.9%、人材ではリクルート31.0%に対してパソナ-2.6%。業界を選んだあとに「なぜこの会社か」を語るには、この差の理由（戦略・強み）を有報から拾うのが近道です。
  • 赤字の理由は必ず確認する。 ソニー（金融事業の切り離し）、東京電力（廃炉の引当金）、ホンダ（EV関連損失）、電通（海外ののれん減損）は、どれも理由がまったく違います。有報の「経営者による財政状態、経営成績及びキャッシュ・フローの状況の分析」に必ず書いてあります。
  • 平均年収は「どの会社の数字か」に注意。 最も高かったのは三菱商事2,113万円、三井物産2,059万円、伊藤忠1,991万円の総合商社3社。ただし持株会社の年収は、実際に多くの社員が働く子会社の年収と違うことがあります（みずほFG 1,167万円に対しみずほ銀行870万円など）。
  • リスクの1番目に何を書くかで、その会社の「怖いもの」が分かる。 人材3社は個人情報、東京電力は福島第一の廃炉、ANAは国際情勢、みずほは日本経済の地盤沈下を挙げています。

有報の読み方：最初に見る5か所

有報は100ページを超えますが、志望動機づくりなら次の5か所で十分です。EDINET（金融庁のサイト）で会社名を検索すると無料で読めます。

  1. 主要な経営指標等の推移第一部 第1売上・利益・ROE・従業員数の5年分。会社の「成績表」です。
  2. 事業の内容第一部 第1どんな事業で稼いでいるかを図で説明しています。
  3. 従業員の状況第一部 第1平均年齢・平均勤続年数・平均年収。持株会社かどうかも確認します。
  4. 経営方針、経営環境及び対処すべき課題等第一部 第2会社が目指す数字と、本気で困っていること。面接で「御社の課題は〜」と話す材料になります。
  5. 事業等のリスク第一部 第2会社が一番恐れていること。ニュースと結びつけると深い志望動機になります。
04

このガイドの使い方

  1. 気になる業界を3つ選び、各ページの「何をしている業界か」と「2026年の今」を読む。共通する「波」がどう影響しているかを意識すると、業界の違いがはっきりします。
  2. 「面接で語れる問い」に、自分の経験から一言で答えてみる。答えやすい問いが多い業界が、志望動機を作りやすい業界です。
  3. 志望企業が決まったら、金融ページ末尾の「3社比較シート」をその業界の同業3社で埋める（有価証券報告書の読みどころもそこにあります）。
  4. 最新動向は、各社のIRページ（決算説明資料・中期経営計画）、日経などの新聞、『業界地図』系の本で補うのが効率的です。

エージェントはなぜ無料？

就活エージェントが学生に無料なのは、学生が入社したときに、採用した企業から紹介料を受け取る仕組みだからです（人材のページの「人材紹介」と同じ稼ぎ方）。そのため、紹介されるのはそのエージェントと契約している企業に限られます。1社に頼りきらず、大学やハローワークの相談と組み合わせるのがおすすめです。

学生が無料で使えて、人に相談できるところだけを載せています。各公式ページの記載は2026年10月25日に確認しました。料金や対象は変わることがあるので、申し込む前に公式ページで確かめてください。
